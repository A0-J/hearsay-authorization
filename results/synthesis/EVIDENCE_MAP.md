# Evidence map: findings → tests, numbers, limits, figures, sources

Generated by `experiments/evidence_map.py` from each run's analysis files and results/synthesis/tables/ (no API calls). Part A lists the pre-registered tests behind the findings; every test of every run is in tables/prereg_tests.csv. Part B links each finding to its evidence. No research question is assigned here.

Status tags as in REPORT.md: **P** pre-registered primary; **S** pre-registered secondary; **D** pre-registered as descriptive; **H** post hoc. Estimates are in percentage points with 95% bootstrap intervals over units; p is the sign-flip test (exact up to 16 units, else 100,000 random sign vectors, so 1e-05 is its floor); Holm p where the pre-registration sets a family. Figure and source paths are relative to results/; REPORT § means results/synthesis/REPORT.md.
