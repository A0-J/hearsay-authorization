# Provenance records

| file | what it holds |
|---|---|
| `run_commits.csv` | Each run's recorded commit and the current commit with the identical tree. The manifests record commits from before a message-only rewrite of the branch history on 2026-11-17. Those commits are on no branch now and git may delete them. |
| `launch_logs/` | The runner's console output for each launch of a paid run, copied on 2026-11-17 from the working session's scratch directory. Files from a sub-folder there carry its name as a prefix (`ad__`, `queue2__`, …). |
| `launch_log_times.csv` | Original creation and modification times (UTC) of those logs. Copying and git do not keep file times. A log is created when the runner starts, so its creation time is the launch time. |
| `../synthesis/tables/run_provenance.csv` | Per run: input, instruction and parser checks, served model, sampling and completeness (generated by `experiments/synthesis.py`). |
